ProntoPC is a one-time paid app sold through the Microsoft Store for $9.99. There is no subscription, no in-app purchase, no trial, no external checkout, no account, and no sign-in. Microsoft Store commerce handles the purchase, and the Store price tier is the price (policy 10.8.4). The AI that builds the repair plan is bundled inside the app and runs entirely on the device, so the app needs no internet connection and no server to function (see the optional Store update check below).

REVIEWER ACCESS (policy 10.3.1): no code, account, sign-in, or test credentials are required. Acquire ProntoPC through the Store (or install the submitted package) and launch it — all functionality is immediately available, and it works with the machine offline.

HOW TO TEST:
1. Launch ProntoPC. There is no UAC prompt on launch and no login.
2. The scan starts automatically after launch. "Reading your system" runs for about a minute, entirely on-device and read-only.
3. The bundled on-device AI presents "Here's what we found" with recommended repairs, plus a live on-device Technician you can ask about the findings.
4. Optionally ask the Technician or uncheck any item, then click Perform Repairs. Windows asks for administrator approval at this repair step only.
5. When finished, the app shows "Your PC has been serviced." A full HTML report is saved to the Desktop and can be opened from the app; you can then close ProntoPC.

Scan, plan, Technician, repair, and report use no network, so you can run the entire test with the machine disconnected after install. The only network use is an optional Microsoft Store update check (StoreContext) a few seconds after launch. If an update is available, a small banner offers it. If the check fails or the machine is offline, it is silently skipped and never blocks scanning or repair.

EXPECTED DURING REPAIRS: if "Reset the Microsoft Store cache" is selected, Windows' own wsreset tool runs and the Microsoft Store app opens when it finishes. This is standard wsreset behavior, and the finding text says so. Temporary-file cleanup is done by ProntoPC directly, with no separate Disk Cleanup window.

PRICING (policy 10.8.4): one-time purchase, $9.99, via the Microsoft Store. No subscription, no in-app purchases, no add-ons, no trial, no randomized purchases. Unlimited runs are included.

GENERATIVE AI: the repair-plan summary and the Technician's replies are written by a generative AI model bundled in the app that runs on the device. It explains the deterministic scan results; it does not decide what was found.

Package candidate: ProntoPC.msixupload version 1.2.25.0. Exact package hashes and current validation results are in docs/CERT_RELEASE_12250.json. No Microsoft certification approval is claimed.

Support: support@prontopc.online

AI CONTENT REPORTING (policy 11.16): A persistent footer offers Report inappropriate AI content, including incoherent, incorrect or harmful responses. Click it in any phase, enter the output and concern, then review/redact before choosing Copy report or Save report, then sending the copied text or saved file to support@prontopc.online. The optional Open in your email app (if installed) action requires a configured email app. Reports are addressed to support@prontopc.online. Opening a draft does not automatically send it. On findings, Report this repair-plan summary selects the displayed summary. Each generated Technician reply has Report this response, which selects that exact reply for review. Copy/Save preserve the complete report when no email client is configured or the draft is too long. No logs or diagnostic files are attached automatically.

MODEL PREPARATION: The model loads silently on-device during the scan. Plan generation waits for successful preparation. No warm-up video or screen is shown.
